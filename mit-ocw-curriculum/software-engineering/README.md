# Software Engineering Track — MIT OCW

Free CS/software-engineering degree-equivalent: 10 courses, ~2-3 semesters full-time,
or ~12-18 months at 15 h/week. Modeled on the MIT EECS CS core.

## Order & rationale

1. **6.0001 Intro to CS & Programming in Python** — get fluent in Python + computation. (Fall 2016)
2. **6.0002 Computational Thinking & Data Science** — optimization, probability, ML intro. (Fall 2016)
3. **6.042J Mathematics for CS** — proofs, discrete structures, probability; the math spine. (Fall 2010)
4. **6.006 Introduction to Algorithms** — the classic algorithms course; do every problem set. (Spring 2020)
5. **6.005 Software Construction** — how to *build* software: specs, testing, OO design, concurrency. (Spring 2016)
6. **6.033 Computer System Engineering** — operating systems + networking + distributed systems theory. (Spring 2018)
7. **6.046J Design & Analysis of Algorithms** — advanced algorithms, NP-completeness, approximation. (Spring 2015)
8. **6.824 Distributed Systems** — hands-on labs (MapReduce, Raft, KV store); the resume-builder. (Spring 2006 edition on OCW)
9. **6.045J Automata, Computability & Complexity** — theory: what computation is, what is infeasible. (Spring 2011)
10. **6.851 Advanced Data Structures** — research-level structures; optional capstone of the track. (Spring 2012)

## Milestones

- After 1-2: you can code real projects.
- After 4-5: interview-level algorithms + software engineering fundamentals.
- After 6-8: systems/distributed depth — build a portfolio from 6.824 labs.
- After 9-10: theory depth — a "real CS degree" level of foundations.

## Tips

- 6.006 and 6.824 are the highest-value courses for career outcomes — do them properly.
- Solutions exist for most problem sets — attempt first, then check.
- Pair with the OSSU community (github.com/ossu/computer-science) for accountability.
- Videos: stream from each course's `videos.txt`, or `yt-dlp -a videos.txt`.

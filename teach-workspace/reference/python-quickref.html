Python Quick Reference

Companion to 0001 Python primer and 0002 Python diagnostic · Sources: 6.01SC Ch.2-3, Guttag Ch.1-4 · print-friendly

Names and binding

x = 5        # binds name x to integer object 5
x = "hi"     # rebinding: x now points at a string — no type declarations
y = x        # y binds to whatever x points at (aliasing)

Functions and scope

def square(n):       # parameter n is local
    return n * n     # return exits and hands back a value

square(4)            # → 16
# A variable bound inside a function is NOT visible outside it.

Collections

lst = [1, 2, 3]        # list  — MUTABLE: lst.append(4), lst[0] = 9
tup = (1, 2, 3)        # tuple — IMMUTABLE: cannot be changed
d = {"a": 1, "b": 2}   # dict  — key → value; d["a"] → 1; d["c"] = 3
len(lst); "a" in d; 2 in lst   # membership/length checks

Loops and comprehensions

for i in range(2, 5):   # iterates 2, 3, 4  (stop is exclusive)
    print(i)

while x < 10:            # loop while condition true
    x += 1

[x * 2 for x in range(3)]        # → [0, 2, 4]   (list comprehension)
{k: len(k) for k in ["a", "bb"]} # → {"a": 1, "bb": 2}

Conditionals

if x > 0:
    print("positive")
elif x == 0:
    print("zero")
else:
    print("negative")

State-machine template (6.01SC Ch.4)

class SM:
    startState = None
    def getNextValues(self, state, inp):
        nextState = state
        return (nextState, inp)   # default: output = input
    def start(self):
        self.state = self.startState
    def step(self, inp):
        (s, o) = self.getNextValues(self.state, inp)
        self.state = s
        return o

Common traps

  • range(2, 5) stops before 5 — the stop is exclusive.
  • Mutable default args / shared lists bite: def f(a=[]) reuses the same list.
  • = assigns; == compares.
  • Tuples are immutable — t[0] = 1 raises TypeError.
  • Dict keys must be hashable (numbers, strings, tuples — not lists).

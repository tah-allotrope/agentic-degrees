  1. What does this statement do?

    x = 5
    • Copies the value five
    • Adds five to variable
    • Creates a new binding
    • Creates an integer type

    Assignment binds the name x to the integer object 5. It does not copy or type-declare — names point at objects.

  2. Which one is a mutable collection?

    • A Python tuple
    • A Python list
    • A Python string
    • A Python integer

    Lists can be changed in place (append, assignment by index). Tuples and strings are immutable; integers are not collections.

  3. What does this program print?

    def f(x):
    return x + 1
print(f(2))
    • 2
    • Error
    • None
    • 3

    The function returns 2 + 1 = 3, and print outputs the returned value.

  4. How do you look up a dictionary value by key?

    • Square brackets
    • Round brackets
    • Curly brackets
    • Angle brackets

    d["key"] — square brackets on a dict name, just like indexing a list.

  5. What does this comprehension produce?

    [x * 2 for x in range(3)]
    • Two four and six
    • One two and three
    • Zero one and two
    • Zero two and four

    range(3) yields 0, 1, 2; doubling gives 0, 2, 4 — "zero two and four".

  6. A variable bound inside a function is:

    • Local to it
    • Global to it
    • Static in it
    • Shared with it

    Function bodies have their own scope; names bound there are invisible outside (unless declared global/nonlocal — a later lesson).

  7. Which values does this loop visit?

    for i in range(2, 5):
    • One two three
    • Two three four
    • Two three five
    • Three four five

    range(start, stop) — stop is exclusive, so 2, 3, 4.

  8. Inside a class method, where does instance data live?

    • The class object
    • The module object
    • The self object
    • The static object

    Instance attributes are stored on the instance, reached through the first parameter, conventionally named self.

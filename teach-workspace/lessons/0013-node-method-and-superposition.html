0013 · Node Method and Superposition

EE track · 6.002 Lec.3–4 · ~30 minutes · mission · github.io

KVL/KCL are laws; this lesson is the procedure. The node method turns any resistive network into equations you can solve mechanically — and superposition lets you split multi-source circuits into one-source pieces.

Why this matters for your mission. "Analyse an arbitrary resistive network by the node method under time pressure" is literally your first mission success criterion. A distribution feeder with two supplies is a multi-source network — the node method solves it whole, superposition solves it one supply at a time.

1 · Node voltages: the unknowns

Pick a reference (ground, 0 V). Every other node gets one unknown voltage e1, e2, …. Branch current between nodes follows Ohm's law:

current from node 1 to node 2 through R: (e1 − e2)/R

2 · The node method in three steps

  1. Write KCL at each non-reference node: sum of currents leaving = 0.
  2. Substitute (ei − ej)/R for each branch current.
  3. Solve the linear system for the node voltages.

N nodes (excl. ground) → N equations, N unknowns. Mechanical every time.

3 · Superposition: one source at a time

In a linear circuit, the response to several sources = sum of responses to each source alone. Turn the others off:

  • Voltage source off → short circuit (0 V).
  • Current source off → open circuit (0 A).

Solve each single-source circuit (often trivial dividers), then add. Never use with nonlinear elements — doubling the input no longer doubles the output there.

4 · Worked numeric: two nodes, one source

10 V source feeds node 1 through R1 = 5 Ω; node 1 to ground through R2 = 5 Ω. One unknown e1. KCL at node 1 (currents leaving):

(e1 − 10)/5 + e1/5 = 0
→ 2e1 − 10 = 0  →  e1 = 5 V
branch currents: (5−10)/5 = −1 A (1 A enters), 5/5 = 1 A (leaves) ✓

Superposition flavor: with a second 10 V source added at node 1 through another 5 Ω, solve each source's contribution (each gives 2.5 V at the node by symmetry of equal resistors… verify: conductance 0.2+0.2+0.2 = 0.6 S; e1 = (10·0.2+10·0.2)/0.6 = 6.67 V; each source contributes 3.33 V) and sum: 3.33 + 3.33 = 6.67 V ✓.

5 · Which tool when

  • Single small circuit → node method directly.
  • Multiple sources, asking "what does this supply contribute" → superposition.
  • Both assume linearity — check before splitting.

Quiz

  1. What is the node method?

    • KCL at nodes yields voltages
    • KVL around loops yields currents
    • Resistor power balance gives heat
    • Sources alone fix every voltage

    Write KCL at each node, substitute (ei−ej)/R, solve for node voltages.

  2. What is superposition?

    • Sum of all resistor values
    • Product of each source contribution
    • Sum of each single-source response
    • Maximum among all source responses

    Total response = sum over sources of the response with only that source on.

  3. When does superposition apply?

    • Only with dependent nonlinear sources
    • Only in fully linear circuits
    • Only with single power source
    • Only when resistors are equal

    Superposition needs linearity: scaling + adding inputs scales + adds outputs.

  4. How are sources turned off?

    • Shorts carry zero voltage drop
    • Opens carry zero branch current
    • Sources keep driving while off
    • Zero source means no excitation

    Voltage off = short (0 V across), current off = open (0 A through) — no excitation from that source.

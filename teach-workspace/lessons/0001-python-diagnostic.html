What does this statement do?
x = 5
Assignment binds the name x to the integer object 5. It does not copy or type-declare — names point at objects.
Which one is a mutable collection?
Lists can be changed in place (append, assignment by index). Tuples and strings are immutable; integers are not collections.
What does this program print?
def f(x):
    return x + 1
print(f(2))
The function returns 2 + 1 = 3, and print outputs the returned value.
How do you look up a dictionary value by key?
d["key"] — square brackets on a dict name, just like indexing a list.
What does this comprehension produce?
[x * 2 for x in range(3)]
range(3) yields 0, 1, 2; doubling gives 0, 2, 4 — "zero two and four".
A variable bound inside a function is:
Function bodies have their own scope; names bound there are invisible outside (unless declared global/nonlocal — a later lesson).
Which values does this loop visit?
for i in range(2, 5):
range(start, stop) — stop is exclusive, so 2, 3, 4.
Inside a class method, where does instance data live?
Instance attributes are stored on the instance, reached through the first parameter, conventionally named self.

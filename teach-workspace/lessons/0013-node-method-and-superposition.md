# 0013 · Node Method and Superposition — notes

EE track · 6.002 Lec.3–4 · week 3 · ~30 min

## What this lesson covers
- Node voltages vs ground; branch current (ei−ej)/R.
- Node method: KCL per node → substitute → solve linear system.
- Superposition: sum of single-source responses; V-off=short, I-off=open.
- Worked: 10 V + 5/5 Ω → e1=5 V; dual-source 6.67 V = 3.33+3.33.
- Tool choice: node method default; superposition for per-supply contribution.

## Why this lesson exists
Mission success criterion 1: node-method analysis under time pressure.
Mission link: two-supply feeder solved whole or one supply at a time.

## Quiz answers
1. KCL at nodes yields voltages. 2. Sum of single-source responses.
3. Only in linear circuits. 4. Off source = no excitation.

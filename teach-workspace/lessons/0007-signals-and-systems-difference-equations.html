0007 · 6.01SC Unit 2 — Signals & Systems, Difference Equations

EE track · 6.01SC Ch.5 (§5.1–5.3) · ~30 minutes · mission · github.io

A signal is a function of a discrete index; a system turns one signal into another. This lesson installs the notation — operator equations and difference equations — that every later circuit, controller, and filter model is written in. It is the bridge from "state machine" (which you can only run) to "system" (which you can analyze).

Why this matters for your mission. A grid inverter, a battery charge controller, a motor turning a head — all are described by a difference equation like y[n] = 0.5·y[n−1] + x[n]. Being able to read that one line, and translate it to a block diagram and back, is the exact skill you need to reason about the response of a BESS controller without building it.

1 · Signals, systems, and sampling

  • A signal is a function of a discrete index n: capital X names the whole signal, lowercase x[n] names its sample at step n.
  • A system transduces an input signal X into an output signal Y. Both are infinite sequences.
  • Sampling turns a continuous signal into a discrete one: x[n] = x(nT), where T is the time between samples.

2 · The primitive signal and three operations

The unit sample δ[n] is 1 at n = 0 and 0 elsewhere. Every signal is built from it with three operations:

  • Scale: c·X means c·x[n].
  • Delay (operator R): RX means x[n−1] — the whole signal shifted one step later.
  • Add: X1 + X2 means x1[n] + x2[n].

Because each operation returns a signal, they compose: 3Δ + 4RΔ − 2R²Δ is a signal with values [3, 4, −2] at steps 0, 1, 2.

3 · Operator equations → difference equations

An operator equation relates whole signals with R, scale, and add: Y = X − RX = (1 − R)X. Read R as "the previous sample". The equivalent difference equation relates samples, and must hold for every n:

y[n] = x[n] − x[n−1]

Difference equations let you compute one sample at a time. For a unit-sample input:

y[0] = x[0] − x[−1] = 1 − 0 =  1
y[1] = x[1] − x[0]  = 0 − 1 = −1
y[2] = x[2] − x[1]  = 0 − 0 =  0   (and 0 forever after)

4 · Block diagrams and state machines

A block diagram uses three primitives: a delay (rectangle, labelled Delay), a gain (triangle, labelled with a number), and an adder (circle, labelled +). The same system Y = X − RX is a Python state machine whose state is the previous input:

class Diff(SM):
    def start_state(self):
        return 0                       # x[-1], the "rest" value
    def get_next_values(self, state, inp):
        return (inp, inp - state)      # state = new previous input

All four representations — operator equation, difference equation, block diagram, state machine — describe the same system. Each makes a different operation easy.

5 · Feedforward systems combine like polynomials

A feedforward system has no feedback: its output never depends on its own past. It is always Y = ΦX where Φ is a polynomial in R. Combining them is polynomial algebra:

  • Cascade (output of one feeds the next) = multiply: Φ2·Φ1.
  • Parallel (sum the outputs) = add: Φ1 + Φ2.
  • The distributive law holds: R(1 − R) = R − R².

Key property: a transient input (finitely many non-zero samples) into a feedforward system gives a transient output. Persistent behaviour — the interesting kind — needs feedback, which is the next lesson.

Quiz

  1. In 6.01 notation, a capital X denotes what?

    • the entire signal sequence
    • a single input sample
    • the delay operator symbol
    • the sampling period value

    Capital X is the whole signal; lowercase x[n] is the single sample at index n.

  2. Which operation shifts a signal later in time?

    • delay by one sample
    • scale by a constant
    • add two signals together
    • advance by one sample

    R X means x[n−1]: the same values, one step later. Advancing (L) is the opposite.

  3. A feedforward system is always which of these?

    • a polynomial in R
    • a ratio of polynomials
    • an infinite geometric series
    • a single scalar constant

    Feedforward means Y = ΦX with Φ a polynomial in R. A ratio (feedback) and a geometric series appear only once feedback is introduced.

  4. A transient input into a feedforward system yields what?

    • a transient output signal
    • a persistent output signal
    • an alternating output signal
    • a constant output signal

    No feedback means the output is a finite sum of scaled, delayed input copies, so a finite input stays finite.

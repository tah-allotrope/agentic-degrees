0008 · LTI Systems, Poles and Convergence

EE track · 6.01SC Ch.5 (§5.4–5.5) · ~30 minutes · mission · github.io

Feedforward gave you a polynomial in R — every transient input stayed transient. Feedback puts a polynomial in the denominator, and a tiny denominator change turns a dying echo into a runaway. This lesson installs the one word that decides which happens: the pole.

Why this matters for your mission. A battery charge controller is a feedback loop: desired SoC minus measured SoC drives a charge command that changes SoC. Whether that loop converges cleanly, rings, or oscillates away is exactly whether the closed-loop pole lies inside the unit circle. Reading a system function like H = 1 / (1 − 0.9R) and saying "pole 0.9, so it decays" is the same judgment you make when you ask if a vendor's controller will hunt.

1 · From operator equation to system function

An LTI system with feedback has an operator equation that mentions Y on both sides. Example (first-order feedback):

Y = X + 0.9·R·Y          (output feeds back, delayed and scaled)

Collect Y terms and factor:

Y − 0.9·R·Y = X  →  (1 − 0.9R)·Y = X  →  Y/X = 1 / (1 − 0.9R)

The ratio Y/X is the system function H(R). For every LTI system it is a rational function — a polynomial divided by a polynomial in R. Feedforward is the special case where the denominator is 1.

2 · The three compositions as algebra on H

  • Sum (parallel): H = H1 + H2
  • Cascade (series): H = H1 · H2
  • Feedback (Black's formula, negative feedback around H1 with return H2): H = H1 / (1 + H1·H2) — the denominator that creates poles.

Because every combination stays rational in R, the whole toolbox is polynomial arithmetic. The denominator you create with feedback is where dynamics live.

3 · Poles are the geometric sequence inside the response

Expand the example H = 1/(1 − 0.9R) as a geometric series in R:

1/(1 − 0.9R) = 1 + 0.9R + 0.9²R² + 0.9³R³ + …

Acting on a unit sample Δ (which is 1 at n=0 and 0 elsewhere), the output samples are y[n] = 0.9ⁿ — a geometric sequence. The base 0.9 is the pole. Every LTI response is a sum of such geometric modes, one per pole. Second-order example:

H = 1 / ((1 − 0.9R)(1 − 0.7R))

has poles 0.9 and 0.7; its unit-sample response is y[n] = A·0.9ⁿ + B·0.7ⁿ for constants A, B set by partial fractions.

4 · Convergence, dominance, and the unit circle

  • Convergence (|p| < 1): pⁿ → 0. Mode decays; a transient input yields a convergent output.
  • Divergence (|p| > 1): pⁿ grows without bound. Even a bounded transient input produces an unbounded output.
  • Sign matters: positive pole → monotonic; negative pole → alternating sign; complex pole pair → sinusoid whose amplitude is |p|ⁿ.
  • Dominant pole: the pole with largest magnitude sets the long-term rate — after a few steps the other modes are negligible and y[n] tracks p_domⁿ.

Worked check — compare p = 0.9 vs p = 1.1:

n : 0    1    2     3      5      10
0.9ⁿ: 1  0.90 0.81  0.73   0.59   0.35   → decays
1.1ⁿ: 1  1.10 1.21  1.33   1.61   2.59   → grows 60% in 5 steps

For the two-pole system with 0.9 and 0.7, by n = 10 0.9¹⁰/0.7¹⁰ ≈ 12× — the 0.9 mode dominates.

5 · Reading a system function at a glance

Given H = (1 + R) / (1 − 0.5R − 0.3R²), factor the denominator to find poles (solve 1 − 0.5r − 0.3r² = 0 in r → poles are reciprocals of roots). If any |pole| ≥ 1, flag instability before simulating. That one-line factoring is the analysis that execution alone can never give you — the same analysis that lets you bound a controller's settling time without running it.

Quiz

  1. What does feedback change about the system function H?

    • It puts a polynomial in the denominator
    • It puts a polynomial in the numerator
    • It removes the delay operator R
    • It makes H a single constant

    Feedback creates Y on both sides → (1 − aR)Y = X → H = 1/(1−aR), a denominator polynomial. Feedforward has no denominator.

  2. For H = 1/(1 − 0.9R), what sequence is the unit-sample response?

    • Constant ones for all n
    • Geometric with ratio 0.9
    • Alternating plus and minus one
    • Zero after the first sample

    1/(1−0.9R)=1+0.9R+0.9²R²+… so y[n]=0.9ⁿ — geometric, base = pole.

  3. Which pole magnitude guarantees a decaying mode?

    • Magnitude greater than one
    • Magnitude less than one
    • Magnitude equal to exactly one
    • Magnitude equal to zero

    |p|<1 → pⁿ→0 (converges). |p|>1 diverges; |p|=1 is marginal.

  4. In a two-pole system with poles 0.9 and 0.7, which dominates long-term?

    • Pole 0.9 dominates the tail
    • Pole 0.7 dominates the tail
    • Both contribute equally forever
    • Neither contributes after n=1

    Largest magnitude wins: 0.9ⁿ/0.7ⁿ grows, so after a few steps the 0.9 mode is the visible tail.

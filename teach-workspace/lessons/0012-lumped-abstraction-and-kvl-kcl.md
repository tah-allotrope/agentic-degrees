# 0012 · Lumped Abstraction and KVL/KCL — notes

EE track · 6.002 Lec.1–2 · week 3 · ~30 min

## What this lesson covers
- Lumped abstraction: elements as points, ideal wires; valid when wavelength ≫ size.
- KVL: loop voltage drops sum to zero.
- KCL: node currents sum to zero.
- Worked divider: 12 V, 4 Ω + 8 Ω → I=1 A, 4 V + 8 V, 12 W balance.
- Laws = topology; element laws = branches; need both.

## Why this lesson exists
Vocabulary for reading one-line diagrams; 0013 makes it procedural.
Mission link: busbar current sums, loop voltage checks.

## Quiz answers
1. Lumped = element is a point. 2. KVL = loop drops sum zero.
3. KCL = node currents sum zero. 4. Together they determine unknowns.

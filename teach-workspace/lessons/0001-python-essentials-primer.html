1. Functions and scope

A function is a named, reusable block. Parameters bind to the caller's arguments when the function is called; calling it creates a new local scope. Inside a function you can read a global but cannot rebind it — the x inside the function is a different object from the x outside.

def f(x):
    x = x + 1          # x here is f's local copy
    return x

x = 3
print(f(x), x)         # 4 3  — the global x is untouched

A function without a return returns None. return only has meaning inside a function, passes a value back to the caller, and ends the function; print writes to the console and does not end the function.

2. Lists, dicts, and mutation

Lists are mutable, ordered sequences. Indexing starts at 0; negative indexes count from the end. Common operations mutate in place (append, extend, remove, pop, sort, reverse) — use them only when you want the side effect.

L = [2, 1, 3]
L.append(5)          # [2, 1, 3, 5]
L.remove(1)          # [2, 3, 5]
L[:]                 # clone: a new list, not an alias

Aliasing: b = a makes b a second name for the same list object — mutating through one name is visible through the other. Copy with a[:] (or list(a)) to get an independent clone.

Dictionaries map keys to values. Lookup by key is d[k]; d.get(k, default) returns default instead of raising KeyError when the key is absent. Adding a new key is just an assignment: d['c'] = 3.

d = {'a': 1, 'b': 2}
d['c'] = 3
len(d)               # 3
d.get('a')           # 1

3. Comprehensions

A list comprehension builds a new list from an iterable in one expression:

xs = [x * 2 for x in range(3)]   # [0, 2, 4]
evens = [x for x in range(10) if x % 2 == 0]
squares = {k: k * k for k in range(4)}   # dict comprehension

4. Iteration patterns

Use a for loop when you know the number of iterations; use a while loop for an "until" condition. range(start, stop, step) counts from start up to stop - 1. To accumulate, initialize before the loop and update inside it.

total = 0
for i in range(4):
    total += i       # 0 + 1 + 2 + 3 = 6

Iterating over a collection's elements directly is more Pythonic than indexing when you do not need the index. Never mutate a list while iterating over it — iterate over a copy instead.

5. Tuple unpacking

Tuples are immutable ordered sequences, written in parentheses. A function can return several values as one tuple, and the caller unpacks it in one assignment:

def qr(x, y):
    return (x // y, x % y)

(q, r) = qr(5, 2)    # (2, 1)

Unpacking also swaps variables cleanly: (x, y) = (y, x).

6. One light recursion example

A recursive function calls itself on a smaller instance of the same problem and needs a base case that stops the recursion:

def fact(n):
    if n <= 1:
        return 1
    return n * fact(n - 1)

fact(3)              # 3 * fact(2) = 3 * 2 * 1 = 6

7. 6.0001 style rules that matter for problem sets

  • Prefer for loops when the iteration count is known; while only for "until" conditions — fewer infinite loops.
  • Never compare a float for exact equality in a loop condition; 0.1 + 0.1 + 0.1 is not 0.3. Count with integers; cast to float only when needed.
  • Do not write if f() == True; write if f(). Return the boolean directly: return not f() instead of an if/else.
  • Write a docstring for every function and class: purpose, inputs, and returns.
  • Never modify a collection while iterating over it; loop over a copy L[:] or build a new collection.

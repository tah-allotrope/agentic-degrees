1. Dictionaries: the two operations you missed

A dict maps keys to values. d[k] reads, d[k] = v writes — and the write is how you both add a new pair and update an existing one. len(d) counts key-value pairs, not values. That is the exact miss from the cold run:

d = {'a': 1}
d['b'] = 2
len(d)               # 2 — two pairs now, not the value 2
d['a'] = 5           # update in place: still 2 pairs
len(d)               # 2 — assignment to an existing key never grows the dict

Three rules that cover the whole diagnostic:

  • d[k] raises KeyError when k is absent; use d.get(k, default) to get a fallback instead.
  • k in d tests key membership (fast — hashed, not a scan).
  • Iterating a dict yields keys by default; use d.items() to unpack key and value together.
plant = {'pv': 5, 'grid': 10}        # kW available
plant['bess'] = 4                    # add a pair
plant['grid'] = 8                    # update a pair
len(plant)                           # 3
plant.get('wind', 0)                 # 0 — no KeyError
for name, kw in plant.items():
    print(name, kw)                  # pv 5 / grid 8 / bess 4

2. Comprehensions: read them left-to-right as a sentence

A list comprehension is one expression that builds a whole list: [expr for var in iterable]. Read it as "for each var in iterable, produce expr". The second diagnostic miss was [x * 2 for x in range(3)] — unfold it by hand: range(3) yields 0, 1, 2; doubling gives 0, 2, 4:

[x * 2 for x in range(3)]          # [0, 2, 4]
[x ** 2 for x in range(4)]          # [0, 1, 4, 9]
[len(s) for s in ['pv', 'bess', 'grid']]   # [2, 4, 4]

Add if cond after the loop to filter — "for each var, if cond, produce expr":

[x for x in range(6) if x % 2 == 1]    # [1, 3, 5] — odds only
[x * 10 for x in range(4) if x != 0]    # [10, 20, 30]

The same shape builds dicts with {key: value for ...} — the one-line way to make a lookup table, which is what 6.0002's problem sets reach for:

{k: k * k for k in range(3)}        # {0: 0, 1: 1, 2: 4}

Practice quiz

Same difficulty, different questions. Answer before reading the explanations.

  1. After running these two statements, what does len(d) return?

    d = {'a': 1}
d['b'] = 2
    • 1
    • 3
    • 2
    • 4

    d['b'] = 2 adds one new pair; the dict holds two pairs, so len(d) is 2. len counts pairs, never values.

  2. With d = {'x': 10}, what does d.get('y', 0) return?

    • 10
    • 0
    • Error
    • None

    get returns the second argument as a fallback when the key is absent, so it is 0 — where d['y'] would have raised KeyError.

  3. After d = {'k': 1} then d['k'] = 2, what does d['k'] return?

    • One
    • Error
    • None
    • Two

    Assignment to an existing key updates it — the dict still has one pair, but its value is now 2. Updating never changes len(d).

  4. What does this loop print?

    d = {'a': 1, 'b': 2}
for k, v in d.items():
    print(k, v)
    • a 1 b 2
    • a b 1 2
    • 1 a 2 b
    • a 1 b 1

    items() yields (key, value) pairs; the unpacking k, v prints each key followed by its value: a 1, then b 2.

  5. What does the expression [x ** 2 for x in range(4)] evaluate to?

    • [1, 4, 9, 16]
    • [0, 1, 2, 3]
    • [0, 4, 16, 36]
    • [0, 1, 4, 9]

    range(4) yields 0, 1, 2, 3; squaring gives 0, 1, 4, 9. [1, 4, 9, 16] is the trap for starting at 1 instead of 0.

  6. What does the expression [x for x in range(6) if x % 2 == 1] evaluate to?

    • [1, 3, 5]
    • [0, 2, 4]
    • [1, 2, 3]
    • [0, 1, 3]

    The filter keeps only odd values from 0-5, so the list is 1, 3, 5. [0, 2, 4] is the even list — the off-by-one in the condition.

  7. What does the expression [len(w) for w in ['go', 'bess', 'grid']] evaluate to?

    • [1, 3, 3]
    • [2, 3, 4]
    • [2, 4, 4]
    • [4, 4, 2]

    len('go') is 2, len('bess') is 4, len('grid') is 4 — the lengths in input order: [2, 4, 4].

  8. What does the expression {k: k * k for k in range(3)} evaluate to?

    • {0: 0, 1: 1, 2: 2}
    • {0: 0, 1: 1, 2: 4}
    • {0: 1, 1: 2, 2: 4}
    • {1: 0, 2: 1, 4: 2}

    A dict comprehension maps keys 0, 1, 2 to their squares: 0, 1, 4. The {0: 0, 1: 1, 2: 2} option forgets to square.

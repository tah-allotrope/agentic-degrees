0012 · Lumped Abstraction and KVL/KCL

EE track · 6.002 Lec.1–2 · ~30 minutes · mission · github.io

Circuits work because we agree to ignore physics. The lumped abstraction shrinks each element to a point — and buys two conservation laws that solve every resistive network in this course.

Why this matters for your mission. Reading a BESS one-line diagram is KVL/KCL fluency: voltages around any loop sum to zero, currents at any busbar sum to zero. Sizing a feeder breaker starts with the KCL sum of branch currents at that bus. This lesson is the vocabulary; 0013 turns it into an algorithm.

1 · The lumped abstraction: what we assume away

Each element becomes a point with terminals; wires are ideal (no resistance, no delay). Valid when signal wavelength ≫ circuit size — true for power electronics switching at kHz over meter-scale hardware. When it breaks (RF, long transmission lines), use distributed models instead.

2 · KVL: voltages around a loop

Kirchhoff's voltage law: around any closed loop, voltage drops sum to zero. Sign convention: + when traversing from + to − terminal.

Loop: +V1 −V2 −V3 = 0   →   V1 = V2 + V3
(series: source equals sum of drops)

3 · KCL: currents at a node

Kirchhoff's current law: at any node, currents sum to zero (in = out). Charge cannot accumulate at a point.

Node: I1 = I2 + I3      (one in, two out)

4 · Worked numeric: two-resistor divider

12 V source across R1 = 4 Ω + R2 = 8 Ω in series. KVL: 12 = V1 + V2. Same current I through both (KCL at the middle node: in = out, one wire each way). Ohm's law per resistor: V1 = 4I, V2 = 8I.

12 = 4I + 8I = 12I  →  I = 1 A
V1 = 4 V, V2 = 8 V.  Check: 4 + 8 = 12 ✓

Power check: source delivers 12·1 = 12 W; resistors take 4 + 8 = 12 W ✓ — conservation holds.

5 · What KVL/KCL don't give you

The laws constrain topology only. Branch relations (Ohm's law, V = IR) constrain elements. You need both — 0013 combines them into the node method.

Quiz

  1. What does lumped abstraction assume?

    • Fields vary inside each element
    • Signals propagate at light speed
    • Each element is a point
    • Wires store significant magnetic energy

    Lumped = elements are points, wires ideal; valid when wavelength ≫ circuit size.

  2. What does KVL state?

    • Loop voltage drops sum zero
    • Node current flows sum zero
    • Power dissipated equals power stored
    • Branch currents match branch voltages

    Around any closed loop, signed voltage drops sum to zero.

  3. What does KCL state?

    • Resistor voltage follows branch current
    • Capacitor blocks all direct current
    • Inductor resists sudden voltage change
    • Node currents sum to zero

    At any node, currents in = currents out — charge cannot pile up at a point.

  4. Why do both laws plus elements suffice?

    • They replace component value equations
    • Together they determine all unknowns
    • They make all resistors linear
    • They eliminate every independent source

    KVL+KCL constrain the topology, element laws constrain each branch — together N equations for N unknowns.
